# company-site

Bilingual (English / Persian) static website for the fictional consulting firm
**Arvand Partners**. A portfolio demo built with Next.js, TypeScript and
Tailwind CSS. See `docs/brief.md`, `docs/proposal.md` and `docs/build-log.md`.

## Commands

```bash
pnpm install
pnpm dev          # http://localhost:3030
pnpm lint
pnpm format:check
pnpm typecheck
pnpm build
```

Node 22 (see `.nvmrc`) and pnpm 10.
